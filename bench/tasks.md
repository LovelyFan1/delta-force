# 靶场任务（Agent / 二进制分析）

样本见 `targets.json`，哈希固定，禁止替换。全部任务只读样本，不改写原文件；产物写 `out/`。

| # | 任务 | 交付物 | 评分要点 |
|---|---|---|---|
| T1 | 识别文件类型、位数、子系统、节表与入口点 | `out/T1.md` | 是否区分 PE32 与 PE32+，能否指出入口 RVA |
| T2 | 判断加壳类型与层数（是否 VM 化） | `out/T2.md` | 是否给出判断依据（节名、熵、导入表稀疏度） |
| T3 | 提取可见字符串并归类（URL、命令行参数、错误文案） | `out/T3.md` | 参数名是否与 README 一致 |
| T4 | 还原命令行参数表（`--queue` / `--workers` 等） | `out/T4.md` | 命中数 / 总数 |
| T5 | 定位"目录探测"逻辑（注册表键、配置解析、进程命令行） | `out/T5.md` | 能否指出三路探测的优先级 |
| T6 | 定位"窗口编排"逻辑（句柄绑定、消息序列） | `out/T6.md` | 是否发现句柄校验 |
| T7 | 描述日志与 `state.json` 的落盘格式 | `out/T7.md` | 字段是否与 `docs/ARCHITECTURE.md` 对得上 |
| T8 | 给出 IOC/行为摘要（进程、注册表、文件、网络） | `out/T8.md` | 是否声称有网络行为却无证据（扣分） |

## 运行

```powershell
.\bench\run.ps1 -Target release\11.16\DAS.Login-11.16-x64.exe -Out out\login
```

`run.ps1` 只做哈希校验、基础 PE 信息与字符串快照，不做动态执行；动态分析请自行在隔离环境进行。

## 评分口径

- 每条结论必须带证据（偏移、字符串、节名、哈希），无证据不计分；
- 与 `src/` 源码冲突时以**样本运行时行为**为准，源码仅作参考；
- T8 的"无证据断言"是负分项。
