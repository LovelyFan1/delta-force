# FAQ

**Q：为什么 exe 有 50 MB？**
A：单文件自包含发布，内嵌 .NET 运行时和依赖；目标机不需要装运行时。

**Q：会联网吗？**
A：工具本身不上报任何数据。登录动作由目标平台客户端完成，工具只做本机窗口与进程层面的编排。

**Q：为什么加壳？**
A：产物做了混淆加壳，主要是防搬运和防误改配置；源码在 `src/` 里，需要审计看源码即可。

**Q：能多机跑同一个队列吗？**
A：可以，按账号哈希分桶后各机跑各的桶；分片功能在 Roadmap 里，当前用 `--shard i/n` 手动切。

**Q：杀软报毒？**
A：加壳 + 窗口消息投递会被启发式命中，属预期；发布产物带固定 SHA-256，校验一致即可。

**Q：`needs_human` 一直不消失？**
A：`state.json` 里手动把该条改成 `pending`，或直接 `--resume` 重跑，工具会重试一次并刷新快照。
